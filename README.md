# Lee Payton

I work in security, GRC, and control assurance. My focus is building practical security programs: clear ownership, evidence people can follow, and decisions that stay with accountable reviewers.

These public projects include local tools, synthetic demonstrations, and research outlines. Their READMEs describe current capabilities and what remains unverified. More to come!

## Selected projects and research

- [Vulncat](https://github.com/lpayt402/vulncat) — Offline vulnerability and inventory reconciliation with source history, reviewable asset attribution, and reports
- [ScubaTank](https://github.com/lpayt402/scubatank) — Offline Microsoft hybrid security assessment from saved evidence, with six implemented correlations and explicit Unknown decisions
- [GYST](https://github.com/lpayt402/gyst) — A local toolkit for organizing scattered information into a source-linked map and surfacing open questions
- [Readiness Lab](https://github.com/lpayt402/readiness-lab) — A local demo for checking evidence and tracing it back to its source, using synthetic sample evidence for hypothetical review workflows
- [Servifide demo](https://github.com/lpayt402/servifide-demo) — A screenshot showcase of versioned policy review, workspace-scoped search, and scoped CSV export using synthetic data
- [M365 Scoped Mail](https://github.com/lpayt402/m365-scoped-mail) — A local mock sender and read-only Exchange validator; live mail authorization remains unproven
- [Compliance Control Map](https://github.com/lpayt402/compliance-control-map) — A self-hosted workspace for tracking controls and supporting evidence, with optional AI suggestions to review
- [Animal Size Estimation](https://github.com/lpayt402/animal-size-estimation) — Exploratory work on estimating animal dimensions from photos and known-size visual references. Inferring weight from dimensions is a separate, species- and use-case-specific question; no model accuracy has been validated.
- [Evidence-led Investigation](https://github.com/lpayt402/evidence-led-investigation) — Evidence-led methods and an offline workbench for linking observations, claims, uncertainty, and human review

I try to make evidence easy to follow, show where the software’s checks end, and leave consequential judgments with a person.
