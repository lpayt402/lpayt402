# Lee Payton

I build and lead security programs where teams have grown faster than the processes that connect them. In a privately held, founder-led company, I’ve had to build support for security work across teams without a top-down mandate. That’s meant making risk clear enough for leaders to decide what to do, then making sure someone owns the follow-through.

## The toolkit

I built three tools for different parts of that job:

- [**GYST**](https://github.com/lpayt402/gyst) compares scattered documents and notes without wiping away contradictions. You can see what each source said and where it disagreed.
- **Servifide** maps what an organization uses, who provides it, which agreements cover it, and what still needs attention. The [public walkthrough](https://github.com/lpayt402/servifide-demo) uses fictional records; the application is private.
- **Obligation Tracker** is my private tool for keeping recurring responsibilities and one-off commitments in view, with owners, check-ins, and links to where the work happened.

## More projects

- [**Compliance Control Map**](https://github.com/lpayt402/compliance-control-map): A workspace for tracking SOC 2 controls, evidence, and open gaps.
- [**Readiness Lab**](https://github.com/lpayt402/readiness-lab): A fictional evidence review that keeps findings, suggestions, and human decisions separate.
- [**ScubaTank**](https://github.com/lpayt402/scubatank): An offline review of hybrid identity risks using saved Microsoft 365 and Active Directory evidence.
- [**Vulncat**](https://github.com/lpayt402/vulncat): An offline way to connect vulnerability findings to assets without losing their source history.
