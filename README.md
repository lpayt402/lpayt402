# Lee Payton

I'm a security engineer. I spend a lot of time building security and compliance processes, and working out how to keep them useful. Outside that work, I like building tools and exploring ideas. Fraud investigation, AI and native Apple apps are a few of my interests.

This is a collection of projects at different stages. Some are local tools you can run. Others are demos with synthetic data, or research that still needs a lot of work. The individual READMEs have the details on what's implemented and what remains unverified. I'll add more here as I go.

## Selected projects and research

- [Vulncat](https://github.com/lpayt402/vulncat): Reconciling vulnerability and inventory data offline. You can look back at the source history and check how an asset was attributed. It also produces reports.
- [ScubaTank](https://github.com/lpayt402/scubatank): Microsoft hybrid security assessment from saved evidence. Runs offline, with six correlations implemented so far. Unknown decisions are recorded as Unknown.
- [GYST](https://github.com/lpayt402/gyst): A local tool for organizing scattered information. The map links back to sources and calls out the questions that are still open.
- [Readiness Lab](https://github.com/lpayt402/readiness-lab): A demo you can run locally to check evidence and trace it back to its source. The samples are synthetic and the review workflows are hypothetical.
- [Servifide demo](https://github.com/lpayt402/servifide-demo): Screenshots showing versioned policy review, workspace-scoped search and scoped CSV export. All of the data shown is synthetic.
- [M365 Scoped Mail](https://github.com/lpayt402/m365-scoped-mail): A local mock sender and a read-only Exchange validator. Live mail authorization hasn't been proven yet.
- [Compliance Control Map](https://github.com/lpayt402/compliance-control-map): A self-hosted place to track controls and the evidence supporting them. You can enable AI suggestions, which are left for a person to review.
- [Animal Size Estimation](https://github.com/lpayt402/animal-size-estimation): Could we estimate an animal's dimensions from a photo using a reference of known size? That's what this research explores. Estimating weight would be a separate step and would depend on the species and use case. No model accuracy has been validated.
- [Evidence-led Investigation](https://github.com/lpayt402/evidence-led-investigation): Methods and an offline workbench for investigations. It links observations to claims and records uncertainty, with human review kept in the process.

I care about being able to follow the evidence. If a tool hasn't checked something, I want that to be clear. The consequential judgments still belong to a person.
