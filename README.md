# Lee Payton

I focus on security, GRC, and control assurance, and I'm interested in practical AI workflows that keep people accountable for decisions.

I build small, inspectable tools for evidence review: deterministic checks for scope, freshness, state, and source references; proposal-only AI patterns; and explicit human review with citations and rationale. My current project, [Readiness Lab](https://github.com/lpayt402/readiness-lab), is a synthetic local demo exploring this workflow with fabricated cloud-provider evidence. It has no live model calls and makes no assessment, authorization, or certification claim.

## Selected projects and research

- [Readiness Lab](https://github.com/lpayt402/readiness-lab) — A local, synthetic demo of evidence checks, source provenance, and human review
- Servifide — A local prototype for connecting services, vendors, agreements, evidence, and actionable gaps; customer-pilot readiness work remains open
- Compliance Control Map — A self-hosted workspace exploring control readiness, evidence links, and optional human-reviewed AI assistance
- SecInABox — A staged security-program framework for discovery, evidence, provenance, and controlled improvement
- Research — Practitioner work on AI capability, evidence, uncertainty, and the steps between task assistance and consequential outcomes

I value useful constraints: source material remains data, citations are checked against current evidence, and human decisions stay separate from system findings. I'm exploring how these choices can make assurance workflows easier to inspect without overstating what automation can establish.

I prefer small, testable steps: make the evidence trail visible, define what the software can validate, and leave consequential judgments with a person.

This profile highlights project work and learning. It does not claim direct FedRAMP delivery experience.
