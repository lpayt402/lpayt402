# Lee Payton

I’m Lee, a security engineer. Much of my work is building security and compliance processes and getting them to work day to day. I also build tools, investigate fraud, and experiment with AI and native Apple apps. This GitHub has a bit of each.

Some projects run locally, some are demos with synthetic data, and others are research outlines. Each README explains what’s working and what still needs to be checked. I’ll add more as I go.

## Selected projects and research

- [Vulncat](https://github.com/lpayt402/vulncat) — Reconciles vulnerability and inventory data offline. Keeps source history, makes asset attribution reviewable, and produces reports.
- [ScubaTank](https://github.com/lpayt402/scubatank) — Assesses Microsoft hybrid security using saved evidence, offline. It has six implemented correlations and records Unknown decisions explicitly.
- [GYST](https://github.com/lpayt402/gyst) — A local toolkit that organizes scattered information into a map linked to its sources and highlights open questions.
- [Readiness Lab](https://github.com/lpayt402/readiness-lab) — A local demo for checking evidence and tracing it back to its source. Uses synthetic samples and hypothetical review workflows.
- [Servifide demo](https://github.com/lpayt402/servifide-demo) — Screenshots of versioned policy review, workspace-scoped search, and scoped CSV export, all using synthetic data.
- [M365 Scoped Mail](https://github.com/lpayt402/m365-scoped-mail) — A local mock sender and read-only Exchange validator. Live mail authorization is still unproven.
- [Compliance Control Map](https://github.com/lpayt402/compliance-control-map) — A self-hosted workspace for tracking controls and supporting evidence. Optional AI suggestions are there for review.
- [Animal Size Estimation](https://github.com/lpayt402/animal-size-estimation) — Early research on estimating animal dimensions from photos and known-size visual references. Estimating weight from those dimensions is a separate question that depends on the species and use case. No model accuracy has been validated.
- [Evidence-led Investigation](https://github.com/lpayt402/evidence-led-investigation) — Methods and an offline workbench for linking observations to claims, recording uncertainty, and keeping human review part of the process.

I want people to be able to follow the evidence and see what the software has actually checked. Consequential judgments stay with a person.
